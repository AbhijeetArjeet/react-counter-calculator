# React Counter & Calculator Project

A basic, clean React application featuring a **Counter** and a **Calculator** without extra styling or external UI libraries.

## Features
- **Counter**: Increment (+), Decrement (-), and Reset buttons.
- **Calculator**: Standard keypad for basic arithmetic (`+`, `-`, `*`, `/`), Clear (`C`), and Equals (`=`).

## How to Run Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. Open your browser at the local URL shown in your terminal (usually `http://localhost:5173`).

## How to Upload to GitHub

1. Open your terminal in this project folder:
   ```bash
   cd react-counter-calculator
   ```

2. Initialize Git and make the first commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: basic React counter and calculator"
   ```

3. Create a new repository on [GitHub](https://github.com/new).

4. Link and push your code:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
